# Цветные линии — Telegram Mini App

Классическая головоломка Lines 98 (9×9, собирай линии от 5 шариков) в виде Telegram Mini App.

## Особенности
- Плавное движение шариков по найденному пути (BFS)
- Арена «Король против тебя»: догони рекордсмена — и корона твоя
- Персонажи-шарики с одёжками (скины): мантия короля, фрак, шуба, треники, спортивка…
- Усиления за ⭐ Telegram Stars: бомба, замена, передышка, продолжение
- Новому игроку — по 3 бустера каждого вида
- Сохранение прогресса в localStorage

## Запуск
Статическая страница — просто откройте `index.html` или разместите на GitHub Pages.
Как Mini App подключается через @BotFather (кнопка меню → URL страницы).

> ⭐ Реальная оплата Stars требует бот-бэкенда (`createInvoiceLink` + обработка `pre_checkout_query`/`successful_payment`). Без него покупки работают в демо-режиме.
